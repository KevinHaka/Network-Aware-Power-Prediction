Write here: What does it mean for a substation's neighbours to be connected to one another? Why is clustering different from degree? (Two sentences.)

When a substation's neighbours are connected to one another, it forms triangular motifs.
Clustering is different from degree because degree merely counts the total number of
direct connections a substation has, whereas the local clustering coefficient measures
the proportion of potential links that actually exist among those neighbouring substations.

eligible=substations.loc[substations['initially_interrupted'].eq(0)].set_index('substation_id').copy()
y=eligible['interrupted_later'].astype(int)
# TODO 4: Set aside 30% of eligible observations for testing.
# Hint: test_size=.30
train_ids,test_ids=train_test_split(y.index,test_size=.3,stratify=y,random_state=SEED)
original=['load_ratio','equipment_age_years']
# TODO 5: Add the second network feature to the model inputs.
# Hint: with_network = original + ['degree', 'local_clustering']
with_network=original+['degree','local_clustering']

def fit_and_score(columns):
    model=make_pipeline(StandardScaler(),LogisticRegression(max_iter=1000))
    model.fit(eligible.loc[train_ids,columns],y.loc[train_ids])
    predicted=model.predict(eligible.loc[test_ids,columns])
    probabilities=model.predict_proba(eligible.loc[test_ids,columns])[:,1]
    scores={'Accuracy':accuracy_score(y.loc[test_ids],predicted),
            'F1':f1_score(y.loc[test_ids],predicted,zero_division=0),
            # TODO 6: Use the predicted probability for ROC AUC.
            # Hint: roc_auc_score(y.loc[test_ids], probabilities)
            'ROC AUC':roc_auc_score(y.loc[test_ids], probabilities)}
    return scores,predicted

base_scores,base_pred=fit_and_score(original)
network_scores,network_pred=fit_and_score(with_network)
results=pd.DataFrame([base_scores,network_scores],index=['Original substation features','Substation + network features'])
display(results.round(3))
fig,axes=plt.subplots(1,2,figsize=(8,3.3))
for ax,pred,title in zip(axes,[base_pred,network_pred],['Original features','With network']):
    ConfusionMatrixDisplay.from_predictions(y.loc[test_ids],pred,ax=ax,labels=[0,1],colorbar=False)
    ax.set_title(title)
plt.tight_layout()

On this test set, adding network features clearly helped: the F1 score increased substantially
from 0.44 to 0.75 and test accuracy rose from 76.7% to 86.0%, with a corresponding rise in ROC AUC.

Confusion matrices reveal that the baseline model suffered from severe false negatives (8 missed disruptions out of 12),
whereas the network-augmented model correctly identified 9 disruptions, reducing false negatives to 3 with only a minimal
rise in false positives (from 2 to 3). While degree simply tallies a substation's direct physical links, the local clustering
coefficient captures neighbour-to-neighbour cross-links and local structural redundancy.

Ethically, prioritizing repairs with such models carries substantial social risk: missed interruptions disproportionately
harm dependent communities through sudden power loss, while false alarms waste public utility resources.
Independent regulatory bodies and local community representatives must actively audit and review these maintenance thresholds.
